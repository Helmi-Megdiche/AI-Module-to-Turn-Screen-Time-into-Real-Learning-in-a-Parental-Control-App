# Project Reports

This folder stores all project reports ("rapports") in Markdown format.

## Naming convention

- Use one file per report.
- Filename format:
  - `YYYY-MM-DD-<phase-or-topic>-report.md`

Examples:
- `2026-04-30-phase2.2-runtime-report.md`
- `2026-05-02-phase2.3-preflight-report.md`

## Rule from now on

Every new report for this project should be saved in this folder using the naming convention above.
